# Security Policy

## Supported Versions

This project only provide updates for latest releases. We recommend always using the latest version to ensure you have the latest security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Heard, please report it privately through GitHub's
"Report a vulnerability" button on the source repository's Security tab
(https://github.com/Yes-Chef-Studio/heard-source/security). Heard is maintained by
Yes Chef Studio and is a fork of [Crikket](https://github.com/redpangilinan/crikket); issues that
also affect Crikket should be reported upstream as well.

Please include as much detail as possible so we can validate and fix the issue quickly:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact and affected components
- Any proof-of-concept, logs, or screenshots

### What to expect

- We aim to acknowledge reports within 72 hours.
- If confirmed, we will work on a fix and coordinate a responsible disclosure timeline.
- Please do not publicly disclose the vulnerability until a fix is available.
